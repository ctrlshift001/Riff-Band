# 前端开发说明

`src/web/` 是 AI4MS 科研工作台的前端开发目录。前端同学可以直接在这个目录下制作完整的系统界面和交互逻辑。

## 开发目标

前端需要呈现一个可操作的管理科学科研工作台，而不是宣传页。界面应覆盖九步科研流程、项目切换、阶段导航、内容编辑、状态反馈和批准/退回等主要操作。

现阶段以做出完整、清晰、可演示的产品界面为主。按钮、弹窗、表单、导航、编辑区和状态变化应具备可体验的交互逻辑。

## 技术方式不限

可以自由选择前端实现方式，例如：

- HTML、CSS 和 JavaScript；
- TypeScript；
- React、Vue 或其他前端框架；
- Vite 或其他构建工具。

现有 `static/` 只是基础原型，可以继续修改，也可以整体替换。无需保留当前 DOM 结构、元素 ID、文件组织或视觉样式。

## 接口要求

前端开发阶段不要求提前保留或严格对接后端接口，可以使用：

- mock 数据；
- 浏览器本地状态；
- 临时 JSON；
- 前端模拟的加载、成功、失败和审批状态。

先把系统界面与交互体验做完整，后续再根据实际页面统一接入 FastAPI。当前 `static/api.js` 也可以修改、替换或暂时不用。

## 建议页面范围

- 项目创建与项目切换；
- 九步科研流程导航；
- 每个阶段的任务区、编辑区和辅助信息区；
- 文献、课题、理论、数据、方法、代码、运行、证据和成果页面；
- HTML 可视化报告预览；
- 弹窗、表单、空状态、加载状态、错误状态和操作反馈；
- 桌面端和移动端基本适配。

前端所需的源码、组件、样式、资源和构建配置都可以放在 `src/web/` 下。除非确实需要联调，不必修改后端研究引擎。
