## 本轮前端变化

- 方法库从 4 个示例扩展为 16 类核心方法，覆盖面板计量、因果识别、准实验、机制模型、优化、运营研究、仿真和因果机器学习。
- 公式库新增独立 L2/L3 页面，先为 12 个高频公式提供深度卡，包含符号映射、成立条件、诊断、Stata 实现、来源与采用说明。
- 仓库已有后端注册表仍是权威目录：28 个方法、47 个公式、40 个数据源；前端深度卡是它的高频交互层，不另建冲突编号体系。后续按 Roadmap 把其余条目补齐为同等深度。
- 方法、公式、诊断规则和当前研究设计形成同一工作台，不再以弹窗代替正式层级页面。
- 智能体回答可以由研究者选择目标位置与追加/替换方式，人工确认后同步到阶段正文，并写入同步审计记录。
- 智能体对话侧栏展示本阶段允许调用的工具与调用边界。

## 产品原则

- AI 只生成候选内容和结构化 patch，不批准自己的输出。
- 方法适配分数不是结论；假设、诊断和失败规则优先。
- 公式必须连接变量定义、分析计划、代码和运行产物。
- 智能体同步内容保持可编辑，并明确标记来源与“待人工审阅”。
- 正式运行、接受风险、阶段批准和发布始终需要人工动作。
